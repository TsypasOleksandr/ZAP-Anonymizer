## Prerequisites (macOS)

- Install Homebrew: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
- OWASP ZAP installed (download from https://www.zaproxy.org/download/ or `brew install --cask zaproxy`)
- Tor installed (`brew install tor` or use Tor Browser)

## Commands Used

### Install Tor on macOS using Homebrew
```bash
brew install tor

## Install Tor Browser on macOS (alternative)
```bash
brew install --cask tor-browser
